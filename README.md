# The Most Honest Outage Line

A single status-page line for the make.fun bounty
[The Most Honest Outage Line](https://make.fun/bounty/u-mgwals-the-most-honest-outage-line-baaf9c81).

The entry is a total-outage message written the way an honest status
page should sound: plain, first person, specific. It names what is
down, admits what cannot be verified from inside the outage, and
invents neither a cause nor an ETA.

## The line

> Everything I run is down: API, dashboard, and my own status page. I can confirm the silence, not the cause - I cannot reach anything that would tell me more.

## Run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (UTF-8, single line).
The script checks the competition gate (1-160 characters, not only
whitespace, one line) before writing.
